# Automatic workspace synchronization

Visible, idle pages check for workspace changes every five seconds and when the browser regains focus or connectivity. Changes from another tab also trigger a check. Incoming changes update sessions, strategies, journal views, chart preferences and the active replay without a restore button or page reload. Navigation stays on the current route.

Updates wait while a form/modal is open or a pointer gesture is in progress. A response received after new local edits started is discarded and checked again later. Local saves still use server revisions: a stale PUT gets a 409, fetches the latest workspace and automatically rebases its pending changes before retrying. Offline drafts remain cached per signed-in account, together with the last acknowledged version used for three-way merging. Older caches without this baseline are merged conservatively.

Independent settings and record edits merge. If both devices make incompatible edits to the same session or strategy, the local pending version stays under its original ID and the other version is preserved with a new ID and a `· sync copy` suffix. A replay snapshot, its instrument/range/capital, and its associated annotations remain together when replay progress diverges; executions from separate versions are never spliced together. Sync copies are ordinary separate sessions/strategies and appear in the normal workspace; review them as separate attempts. Deletion of an unchanged record propagates; a concurrent edit is preserved. Validation and collection limits still apply, so data that cannot be merged within those limits remains pending rather than silently truncated.

The server's optimistic revision checks, authentication and per-user isolation remain unchanged. The refresh loop pauses in hidden tabs. Unchanged revision checks return an empty 204 response using a database query that selects only the revision; changed checks fetch workspace metadata. Historical candle archives are loaded only when an updated active session requires them. This applies to workspace state, not scheduled MT5 broker imports, which still require Sync now.
